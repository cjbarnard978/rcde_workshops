## Workshop Description

This workshop introduces deep learning in Python with the Keras library. Students will master basic skills in deep learning and the Keras Library, and be able to perform programming tasks using deep neural networks. Students will learn how to use Keras for classification/regression problems, application
of CNN for image classification, and use of RNN LSTM for time series forecasting.

## Prerequisites
The necessary pre-requisite for this workshop is **Machine Learning in Python**
